## Técnicas de sondeo (solo lectura, con la anon key)

- **¿Existe la columna?** `GET /rest/v1/<tabla>?select=<col>` → `42703 column … does not exist` = no existe; 200 = existe.
- **¿Es válido el label de un enum?** `?estado=eq.<label>` → 400 `invalid input value for enum` = inválido; 200 = válido.
- **¿Existe la función y sus params?** `POST /rpc/<fn>` con `{"p_dummy":null}` y mirar si el error dice `... have parameter` (con `{}` solo es inconcluso). El `hint` del PGRST202 a veces **revela el nombre real del parámetro** ("Perhaps you meant … p_name") — ahí se descubrió que `upsert_cliente` usa `p_name`.
- El OpenAPI de PostgREST no expone definitions ni rpcs.

## Frontend / testing — trampas ya conocidas

- `react-hooks/set-state-in-effect` (eslint v7) flaggea cualquier setState alcanzable desde un `useEffect`, incluso tras `await`. **Solución verificada con probes**: cargar datos en effect con estilo `.then(callback)` pasa; `async/await` en callee no.
- CoreUI modal = clase `modal fade show` (no `modal show`) — los XPath por `contains(@class,'modal show')` fallan; usar dos predicados.
- Headless Edge: `--window-size=1440,1250` (viewport real queda ~1163px de alto; con 900 el botón Agregar cae fuera y `elementFromPoint` da null).

- `supabase.rpc` devuelve `{data, error}` (no lanza); el error real del RPC viene en `error.message`. **`supabase.rpc(...).catch` NO existe** en esta versión → usar `try/await` o `.then` (ver bug de `POSPage.jsx:146`).
- **Verificar una venta sincronizada por RPC, no por la cola:** el motor **borra** el evento al confirmarlo (`SCRIPT_EVENTO` devuelve `null` = ya sincronizado) y **remapea el id local** por el del servidor (`id-remapeado`) → el folio de la fila local cambia después del push; consultar `get_ventas_historial` (con `p_busqueda: null`, no por folio: `p_busqueda` busca folio textual).
- **`.modal.show` (CoreUI) intercepta clics**: antes de tocar una fila de una tabla detrás de un modal hay que cerrar **todos** los `.modal.show` o se lanza `ElementClickInterceptedError`.
- **Con red, abre una vez cada ruta lazy** que usarás offline (dev server): sin red el import dinámico falla y tumba todo el árbol de React (`Failed to fetch dynamically imported module`).
